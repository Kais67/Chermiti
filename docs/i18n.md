# Langues (français, arabe RTL, anglais)

* **Français** : langue source et par défaut. **Arabe** : direction RTL appliquée à toute la page (`<html dir="rtl" lang="ar">`), police Noto Sans Arabic, règles CSS miroir. **Anglais** : LTR.
* La langue se choisit sur l'écran de connexion et dans le menu ; elle est mémorisée sur l'appareil ; à défaut, la langue par défaut de l'école (champ `langue_defaut`).
* **Centralisé** : `client/src/i18n/ar.json` et `en.json` (clé = texte français). Dans le code : `tt('Texte français')` ou `tt('Bonjour {nom}',{nom})`. Les messages d'erreur du serveur (en français) sont traduits côté client avec les mêmes catalogues (motifs `{n}` acceptés).
* **Ajouter/modifier un texte** : écrire `tt('…')`, puis `npm run i18n:cles` (liste), compléter les deux JSON, puis `npm run i18n:verifier --prefix client` (échoue s'il manque une traduction).
* **Ajouter une langue** : créer `xx.json`, déclarer la langue dans `LANGS` (`client/src/i18n/index.jsx`, avec `dir`), ajouter la validation `langue_defaut` côté serveur.
* **Limites connues** : PDF (reçus, bulletins) en français ; dates/nombres suivent la langue (`Intl`, chiffres latins) ; la langue n'est pas encore enregistrée par utilisateur.
