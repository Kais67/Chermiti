# Guide enseignant

- **Emploi du temps** : vos cours de la semaine ou d'un jour (menu « Vue »).
- **Évaluations** : créez une évaluation (classe, matière, trimestre, type : contrôle continu ou examen, barème). Vous ne pouvez agir que sur les classes et matières qui vous sont affectées (titulaire, créneau ou affectation).
- **Saisie des notes** : choisissez l'évaluation, saisissez les notes, « Enregistrer ». La note ne peut pas dépasser le barème. Les parents sont notifiés.
- **Absences** : signalez une absence ; le parent peut la justifier, la direction la valide.
- **Devoirs** : « + Nouveau devoir » (pièce jointe possible). Ouvrez un devoir pour voir les dépôts (rendu, en retard, non rendu), attribuer une note et un commentaire, joindre la correction (visible des élèves et parents après la date de remise), modifier ou supprimer. La suppression d'un devoir déjà déposé demande une confirmation.
- **⭐ Étoiles** : récompensez un effort ou un bon comportement (menu Étoiles) ; le parent et l'élève sont prévenus.
- **Messagerie** : vous écrivez aux parents de vos élèves et à l'administration. Un message envoyé est définitif ; les brouillons restent modifiables.
